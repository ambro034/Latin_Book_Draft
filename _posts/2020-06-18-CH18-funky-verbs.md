### Principles of Grammar

Although you have learned several irregular verbs—verbs like *ferō* that do not follow a typical conjugation—there are other types of verbs that are regular but just have odd rules. In this chapter we will cover several types of these verbs. They are not particularly difficult; they just need to be flagged in your mind (and flash cards) as different—or *funky*. The biggest challenge to this is just remembering the different patterns of the verbs, so when you memorize them, take care to use a different color on your flash card, circle them, or use any method that will best mark them as unique.

Other verbs with irregular forms or unique patterns (e.g., *volō*) are listed in Appendix #

### Principles of Latin

Listed below are the different types of funky verbs. Although the list can be daunting at first, remember that there is no new grammar to learn; these verbs just have their own special pattern. The vocabulary entry will also clue you in to what pattern you should expect.

Intransitive verbs that take dative objects: These are simply verbs that do not have typical transitive properties. A good example in Latin and English are the verbs *obey* and *study*. In English, we use the verb transitively “I obey my professor and study my homework,” but we are not actually acting on the direct objects, in the same way we might say “I chew my food and pet my dog.” The professor and homework do not actually receive any action from the verb. In Latin, many verbs like this take Dative objects.

Some of these verbs (full vocabulary with principal parts is at the end of the chapter) are:

parēre: to obey (to be obedient *to* someone)  
placēre: to please (to be pleasing *to* someone)  
obstare: to hinder (to be a hindrance to someone)

nocēre: to harm (to be harmful to someone)

credere: to trust (to entrust yourself to someone)

Deponent verbs: These verbs are common in Latin (and other older languages). They look passive, but we translate them as active. These verbs still belong to the usual conjugations; their principal parts will just look passive. A first conjugation verb will appear in the dictionary like this: *hortor, hortārī, hortātus sum: to urge*. Since there is no passive form to these verbs, they do not have a typical fourth principal part. Like any other verbs, they can be transitive, intransitive, and even take indirect statements. The conjugation is determined by the infinitive, as usual, but the passive infinitive form: -ārī (1); -ērī (2); -ī (3^rd^, 3^rd^ –io); -īrī (4th)

Some of these verbs (a list of full vocabulary with principal parts is at the end of the chapter) are:

sequī: to follow

patī: to endure

precārī: to pray

Special Deponent Verbs: there are five verbs that obey the typical rules of deponent verbs (they look passive, but they are active), but they take *ablative objects instead of accusative direct objects*. The five special deponent verbs (full list of principal parts is below) are *potior* (to obtain, capture), *utor* (to use, enjoy), *fruor* (to enjoy, profit in), *fungor* (to perform, execute), and *vescor* (to eat). These five verbs, which all generally refer to gaining or using something, go by the acronym PUFF-V.

Semi Deponent Verbs: the last of the funky verbs are semi-deponent verbs. These are perhaps the funkiest of them all. These verbs are deponent only in the perfect system. For example, *audeō, audēre, ausus sum* (to dare), seems like a usual verb in the present, imperfect, and future, but in the perfect tenses it is deponent (so *ausus sum* means “I dared,” not “I have been dared”). Fortunately, there are not many of these verbs in Latin.

const depState =
    depQuestions.map(function(){
        return new Set();
    });


function normalizeDep(text) {

    return text
        .toLowerCase()
        .normalize("NFD")
        .replace(/[\u0300-\u036f]/g, "")
        .replace(/[.,!?;:'’"]/g, "")
        .replace(/\s+/g, " ")
        .trim();
}


function sameDepTypes(studentSet, correctArray) {

    if (
        studentSet.size !==
        correctArray.length
    ) {
        return false;
    }

    return correctArray.every(function(type){
        return studentSet.has(type);
    });
}


function buildDepQuiz() {

    const quiz =
        document.getElementById("dep-quiz");

    quiz.innerHTML = "";


    depQuestions.forEach(function(q, i) {

        const card =
            document.createElement("div");

        card.className =
            "dep-question";


        const buttons =
            depTypes.map(function(type){

                return `
                    <button
                        type="button"
                        class="dep-choice"
                        data-q="${i}"
                        data-type="${type}"
                        aria-pressed="false">
                        ${type}
                    </button>
                `;

            }).join("");


        card.innerHTML = `

            <div class="dep-sentence">
                ${i + 1}. ${q.sentence}
            </div>

            <div class="dep-section">

                <span class="dep-label">
                    Target verb:
                    <strong>${q.target}</strong>
                </span>

                <span class="dep-label">
                    Underline all that apply:
                </span>

                <div class="dep-options">
                    ${buttons}
                </div>

            </div>


            <label
                class="dep-label"
                for="dep-translation-${i}">
                Translate:
            </label>

            <input
                type="text"
                id="dep-translation-${i}"
                class="dep-input"
                autocomplete="off"
                placeholder="Type the English translation">


            <div
                id="dep-feedback-${i}"
                class="dep-feedback"
                aria-live="polite">
            </div>
        `;


        quiz.appendChild(card);

    });


    quiz.querySelectorAll(
        ".dep-choice"
    ).forEach(function(button){

        button.addEventListener(
            "click",
            function(){

                const q =
                    Number(button.dataset.q);

                const type =
                    button.dataset.type;


                if (
                    depState[q].has(type)
                ) {

                    depState[q].delete(type);

                    button.classList.remove(
                        "dep-selected"
                    );

                    button.setAttribute(
                        "aria-pressed",
                        "false"
                    );

                } else {

                    depState[q].add(type);

                    button.classList.add(
                        "dep-selected"
                    );

                    button.setAttribute(
                        "aria-pressed",
                        "true"
                    );

                }

            }
        );

    });

}


window.checkDepQuiz = function() {

    let score = 0;

    const possible =
        depQuestions.length * 2;


    depQuestions.forEach(function(q, i){

        const feedback = [];


        /* VERB TYPE */

        if (
            sameDepTypes(
                depState[i],
                q.types
            )
        ) {

            score++;

            feedback.push(
                `<div class="dep-correct">
                    ✓ Verb identification correct.
                </div>`
            );

        } else {

            feedback.push(
                `<div class="dep-incorrect">
                    ✗ Correct identification:
                    <strong>${q.types.join(" + ")}</strong>.
                </div>`
            );

        }


        /* TRANSLATION */

        const student =
            normalizeDep(
                document.getElementById(
                    `dep-translation-${i}`
                ).value
            );


        const correct =
            q.translations.some(
                function(answer){

                    return (
                        student ===
                        normalizeDep(answer)
                    );

                }
            );


        if (correct) {

            score++;

            feedback.push(
                `<div class="dep-correct">
                    ✓ Translation correct.
                </div>`
            );

        } else {

            feedback.push(
                `<div class="dep-incorrect">
                    ✗ One correct translation is:
                    <strong>${q.display}</strong>.
                </div>`
            );

        }


        feedback.push(
            `<div class="dep-note">
                ${q.note}
            </div>`
        );


        document.getElementById(
            `dep-feedback-${i}`
        ).innerHTML =
            feedback.join("");

    });


    document.getElementById(
        "dep-score"
    ).textContent =
        `Score: ${score} / ${possible}`;

};


window.resetDepQuiz = function() {

    depState.forEach(function(set){
        set.clear();
    });

    buildDepQuiz();

    document.getElementById(
        "dep-score"
    ).textContent = "";

};


buildDepQuiz();

})();
</script>
